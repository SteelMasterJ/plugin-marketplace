# js-site-builder (Antigravity)

Builds complete, modern, WCAG 2.1 AA accessible, responsive (`320px+`) websites from scratch using `@steelmasterj/js-components`, Vue 3 Composition API (`<script setup>`), Vite, `vue-router`, and semantic vanilla HTML/CSS with minimal dependencies.

- **Skill**: `js-site-builder`
- **Agent**: `js-site-architect`
- **Component Gap Gate**: Stops and asks the user before inventing missing UI primitives — offering to build a new reusable component in `@steelmasterj/js-components` or a lightweight site-local alternative.
